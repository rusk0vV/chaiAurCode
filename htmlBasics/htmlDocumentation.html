Core Document Anatomy (Boilerplate)

<!DOCTYPE html> Declaration

An instruction to the web browser declaring that the page is written in modern HTML5. It is not an HTML tag, but a mandatory document declaration placed at the very top of the file.

💡
Why it matters: Ensures the browser renders in standard modern HTML5 mode instead of bug-prone "quirks mode".
<!DOCTYPE html>
<html> ... </html> Root Container

The top-level root element that encloses every other element on the entire web page.

Key Attributes
lang="en" — Specifies document language. Essential for SEO, translation tools, and screen reader pronunciation.
<html lang="en">
  <!-- head and body go inside here -->
</html>
<head> ... </head> Metadata Container

Holds invisible configuration data and metadata about the document for browsers and search engines. Never displayed as body text.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document Title</title>
</head>
<body> ... </body> Document Canvas

Wraps all visible content rendered on screen: headings, paragraphs, images, tables, forms, and links.

Heading Elements (<h1> to <h6>)

<h1> through <h6> Block Level

Headings establish semantic hierarchy. They are block-level elements starting on a new line and spanning full width.

Hierarchy & Best Practices
<h1>: Main page title. Only ONE <h1> per page for SEO.
<h2> to <h6>: Progressively smaller subheadings.

Semantic HTML5 Layout & Meaning

<header>, <nav>, <article>, <section>, <footer> Semantic Layout

Semantic tags clearly describe their meaning to both the browser and the developer, unlike a generic <div>.

Semantic Structure Elements
<header> — Container for introductory content, site logo, and top navigation.
<hgroup> — Groups a set of headings (e.g. an <h1> title together with an <h2> subtitle or tagline).
<nav> — Dedicated section containing major navigation links. Screen readers use this to let users jump straight to site menus.
<article> — Self-contained, independent piece of content that could be distributed or reused on its own (e.g. a blog post, news story, or review).
<section> — Thematic grouping of content, typically with its own heading.
<time datetime="YYYY-MM-DD"> — Represents a human date and provides machine-readable ISO format in the datetime attribute.
<code> — Inline tag representing a computer code snippet.
<footer> — The footer of a document or section containing copyright, author details, and legal links.
<address> — Provides contact information for the author/owner. Renders in italics by default.
&copy; — HTML character entity for the copyright symbol (©).
<header>
  <hgroup>
    <h1>Learn to create websites</h1>
    <h2>You can learn with hitesh</h2>
  </hgroup>
  <nav>
    <ul>
      <li><a href="#">Home</a></li>
    </ul>
  </nav>
</header>

<article>
  <hgroup>
    <h1>Article Title</h1>
    <h3><time datetime="2024-08-02">August 2nd</time></h3>
  </hgroup>
  <section>
    <p>Article text content...</p>
    <code>console.log("hitesh")</code>
  </section>
</article>

<footer>
  <address>Add Your Address Here</address>
  <p>&copy; Chaicode 2024</p>
</footer>

Forms & User Inputs (<form>, <label>, <input>, <select>, <button>)

<form> Controls & Attributes Interactive Input
Crucial Difference: name vs id
id="..." — Client-side identity. Must be unique on the page. Links with <label for="id"> and is used by CSS and JS. Never sent to the server.
name="..." — Server-side key. Sent to backend database as key=value upon form submission. Inputs without a name are ignored during submit!
Form Controls & Types
<input type="text"> — Single-line text input with placeholder="...".
<input type="password"> — Masked input for sensitive passwords.
<input type="checkbox"> — Toggle checkbox.
<input type="color"> — Color palette picker.
<select> + <option value="..."> — Dropdown list selector.
<button type="submit|reset"> — Submits or resets the form.

Media Elements (<img>, <figure>, <figcaption>, <video>)

<img> Void / Self-closing

Embeds an image into the document with enhanced attributes:

Image Attributes
src="..." — Relative or absolute file path to the image.
alt="..." — Descriptive alternative text for screen readers and SEO.
title="..." — Hover tooltip text shown when hovering cursor over the image.
width="..." — Explicit image width in pixels (e.g. width="200" or width="200px").
<figure> and <figcaption> Semantic Media Container

<figure> wraps self-contained media (like an image, chart, or code snippet), while <figcaption> provides an official semantic caption.

<figure>
  <img src="images/hc.png" alt="Dinosaur skeleton" width="200">
  <figcaption>A T-Rex on display in the Manchester University Museum.</figcaption>
</figure>
Rendered Figure & Caption:
<video> ... </video> Native Video Player

Embeds a native HTML5 media player directly in the browser without requiring third-party plugins.

Video Attributes
src="..." — Video file path (e.g. .mp4, .webm).
controls — Boolean attribute displaying the browser's built-in playback bar (play/pause, volume, time scrubber, fullscreen).
width="..." — Dimensions of the video player.
controlslist="noremoteplayback nodownload" — Customizes browser control options, such as disabling remote cast or download buttons.
<video src="./images/chai_pe_charcha-1080.mp4" width="400px" controls controlslist="noremoteplayback"></video>
