Core Document Anatomy (Boilerplate)

<!DOCTYPE html> Declaration

An instruction to the web browser about what version of HTML the page is written in. It is not an HTML tag, but a mandatory document declaration.

💡
Why it matters: Ensures the browser renders in standard modern HTML5 mode instead of bug-prone "quirks mode". Always line 1 of any HTML file.
<!DOCTYPE html>
<html> ... </html> Root Container

The top-level root element that encloses every other element on the entire web page.

Key Attributes
lang="en" — Specifies the human language of the document (English). Crucial for search engine indexing (SEO), browser translators, and screen reader text-to-speech pronunciation.
<html lang="en">
  <!-- head and body go inside here -->
</html>
<head> ... </head> Metadata Container

Holds invisible configuration data and metadata about the document for browsers and search engines. Content inside <head> is never displayed as body text on the page.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document Title</title>
</head>
<meta> Void / Self-closing

Provides technical specifications regarding character encoding, viewport display, authors, and keywords.

Essential Meta Attributes
charset="UTF-8" — Encodes text using Unicode (UTF-8). Prevents garbled symbols and supports all international languages, special characters, and emojis.
name="viewport" + content="width=device-width, initial-scale=1.0" — Controls responsive mobile scaling. Prevents mobile devices from showing tiny zoomed-out desktop layouts.
<title> ... </title> Metadata Text

Sets the title shown on the browser tab, in history, bookmarks, and as the clickable headline on Google search results.

<title>First HTML - Chai Aur Code</title>
<body> ... </body> Document Canvas

Wraps all visible content rendered on screen: headings, paragraphs, images, links, buttons, lists, and forms.

<body>
  <h1>Hello from Ali</h1>
</body>

Heading Elements (<h1> to <h6>)

<h1>, <h2>, <h3> Block Level

Headings establish semantic hierarchy and an outline for content structure. They are block-level elements, meaning each begins on a new line and spans the full available width.

Hierarchy & SEO Rules
<h1>: Primary heading. Only 1 per page for good SEO and clear topic definition.
<h2>: Major section titles.
<h3>: Sub-topics inside an <h2> section.
<h1>Lorem ipsum dolor sit amet.</h1>
<h2>Major section heading</h2>
<h3>Detailed sub-topic point</h3>

Media Elements (<img>)

<img> Void / Self-closing

Embeds an image into the document. It does not have a closing </img> tag because it does not wrap text content.

Required Attributes
src (Source) — Path to the image file. Can be:
  • Relative path: ./images/Passport Photo.jpg (Local to project folder)
  • Absolute URL: https://example.com/logo.png (Web hosted)
alt (Alternative Text) — Written fallback text describing the image:
  • Accessibility: Spoken aloud by screen readers for visually impaired users.
  • Fallback: Rendered on screen if the image fails to load or link is broken.
  • SEO: Helps search engines understand what is in the picture.
<img src="./images/Passport Photo.jpg" alt="Passport Photo">

Hyperlinks & Anchors (<a>)

<a> ... </a> Inline Element

Creates hyperlinks that allow users to navigate between pages, download files, open email clients, or jump to specific page sections.

Attributes & Link Types
href (Hypertext Reference) — Destination URL.
External Link: href="https://www.chaicode.com" (Navigates to another website).
Internal / Local Link: href="./01_intro.html" (Navigates to another file in your project).
<!-- External Web Link -->
<a href="https://www.chaicode.com">Go to Chai Aur Code</a>

<!-- Internal Local File Link -->
<a href="./01_intro.html">Go to intro.HTML</a>
