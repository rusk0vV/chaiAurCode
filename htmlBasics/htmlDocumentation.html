Core Document Anatomy (Boilerplate)

<!DOCTYPE html> Declaration

An instruction to the web browser declaring that the page is written in modern HTML5. It is not an HTML tag, but a mandatory document declaration placed at the very top of the file.

💡
Why it matters: Ensures the browser renders in standard modern HTML5 mode instead of bug-prone "quirks mode".
<!DOCTYPE html>
<html> ... </html> Root Container

The top-level root element that encloses every other element on the entire web page.

Key Attributes
lang="en" — Specifies the human language of the document (English). Crucial for search engine indexing (SEO), browser translators, and screen reader text-to-speech pronunciation.
<html lang="en">
  <!-- head and body go inside here -->
</html>
<head> ... </head> Metadata Container

Holds invisible configuration data and metadata about the document for browsers and search engines. Content inside <head> is never displayed as body text on the page.

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document Title</title>
</head>
<meta> Void / Self-closing

Provides technical specifications regarding character encoding, viewport display, authors, and keywords.

Essential Meta Attributes
charset="UTF-8" — Encodes text using Unicode (UTF-8). Prevents garbled symbols and supports all international languages, special characters, and emojis.
name="viewport" + content="width=device-width, initial-scale=1.0" — Controls responsive mobile scaling. Prevents mobile devices from showing tiny zoomed-out desktop layouts.
<title> ... </title> Metadata Text

Sets the title shown on the browser tab, in history, bookmarks, and as the clickable headline on Google search results.

<title>First HTML - Chai Aur Code</title>
<body> ... </body> Document Canvas

Wraps all visible content rendered on screen: headings, paragraphs, images, tables, forms, and links.

<body>
  <h1>Hello from Ali</h1>
</body>

Heading Elements (<h1> to <h6>)

<h1> through <h6> Block Level

Headings establish semantic hierarchy and an outline for content structure. They are block-level elements, meaning each begins on a new line and spans the full available width.

Hierarchy & Best Practices
<h1>: Main page title. Only ONE <h1> per page for SEO and topic clarity.
<h2>: Major section headings.
<h3>: Sub-sections inside an <h2>.
<h4>: Sub-topics inside an <h3>.
<h5>, <h6>: Deep granular subsection titles.
<h1>Lorem ipsum dolor sit amet.</h1>
<h2>Lorem ipsum dolor sit amet consectetur, adipisicing elit. Fuga, voluptatem?</h2>
<h3>Lorem ipsum dolor sit amet.</h3>
<h4>Lorem ipsum dolor sit amet consectetur adipisicing elit. In, veritatis?</h4>

Structural Containers (<div>)

<div> ... </div> Block Level Container

<div> stands for division. It is a generic container used to group multiple elements together. By itself, it has no visual appearance or semantic meaning, but it is one of the most widely used tags in web development.

💡
Why we use <div>:
  • Grouping: Bundling headings, paragraphs, and lists into a single logical section.
  • CSS Styling: Applying backgrounds, borders, padding, cards, and grid/flexbox layouts.
  • JavaScript Manipulation: Selecting a group of related elements together.
<div>
  <h3>Lorem ipsum dolor sit amet.</h3>
  <h4>Lorem ipsum dolor sit amet consectetur adipisicing elit.</h4>
  <p>Lorem ipsum <strong>Bruh </strong>dolor sit amet.</p>
</div>

Paragraphs & Text Formatting (<p>, <strong>)

<p> ... </p> Block Level

Represents a paragraph of text. Browsers automatically add vertical margin (empty space) before and after each paragraph to keep text clean and readable.

<p>Lorem ipsum dolor sit amet.</p>
<strong> ... </strong> Inline Element

Indicates that its contents have strong importance, seriousness, or urgency. Browsers render the enclosed text in bold font weight by default.

Semantic Importance: <strong> vs <b>
<strong>: Semantic element. Indicates that the text is important. Screen readers may announce it with emphasis or different tone.
<b>: Presentational element. Merely makes text look bold visually with no special importance attached.
<p>Lorem ipsum <strong>Bruh </strong>dolor sit amet.</p>

Lists (<ul>, <li>)

<ul> and <li> Block Level

HTML provides list elements to display bulleted or numbered items neatly:

List Elements Breakdown
<ul> (Unordered List) — Container for a collection of items with no numerical order. Rendered with circular bullet points by default.
<li> (List Item) — Represents an individual item within a list. Must always be placed inside a parent list (<ul> or <ol>).
<ul>
  <li>Topic 1</li>
  <li>Topic 2</li>
  <li>Topic 3</li>
</ul>

Tables (<table>, <tr>, <th>, <td>)

<table> Block Level Table Container

Used to present structured, tabular data in grid rows and columns. Never used for general page layout—strictly for tabular data.

Table Elements Breakdown
<table> — The root wrapper element for the entire table.
<tr> (Table Row) — Represents a horizontal row of cells.
<th> (Table Header) — Represents a header cell. Rendered as bold and centered by default. Crucial for screen reader accessibility.
<td> (Table Data) — Represents a standard data cell holding values, text, or numbers.
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
    <th>City</th>
  </tr>
  <tr>
    <td>John</td>
    <td>25</td>
    <td>New York</td>
  </tr>
</table>

Forms & User Inputs (<form>, <label>, <input>, <select>, <button>)

<form> Block Level Container

Collects interactive user inputs (text, passwords, selections, buttons) and prepares them to be sent to a web server.

<label> and <input> Inline Elements

The primary building blocks of all interactive web forms:

Key Elements & Attributes
<label for="id"> — Accessible caption for an input. Clicking the label focuses the corresponding input (linked via matching for and id).
<input> (Void / Self-closing) — Flexible input field determined by its type attribute.
type="text" — Standard single-line plain text box.
type="password" — Masks user input with dots/asterisks for security.
type="checkbox" — Square toggle box for true/false or multi-option choices.
type="color" — Native browser color wheel/palette selector.
placeholder="..." — Temporary light gray hint text shown inside empty input fields.
name="..." — The key/variable name submitted with the form data (e.g. email=test@mail.com).
<!-- Text Input with Label & Placeholder -->
<label for="email">
  Email:
  <input type="text" name="email" id="email" placeholder="test@example.com">
</label>

<!-- Password Input -->
<label for="password">
  Password:
  <input type="password" name="password" placeholder="enter your password">
</label>
<select>, <option>, <button> Form Controls

Dropdown menus and action trigger buttons:

Dropdowns & Action Buttons
<select> — Creates a collapsible dropdown menu list.
<option value="..."> — Individual selectable item. The value is sent to the server.
<button type="submit"> — Submits the form data.
<button type="reset"> — Clears all inputs in the form back to their default values.
<!-- Dropdown Selection -->
<select name="Games">
  <option value="Cricket">Cricket</option>
  <option value="Baseball">Baseball</option>
</select>

<!-- Form Buttons -->
<button type="submit">Submit</button>
<button type="reset">Reset</button>

Media Elements (<img>)

<img> Void / Self-closing

Embeds an image into the document. It does not have a closing </img> tag because it does not wrap text content.

Required Attributes
src (Source) — Path to the image file (relative: ./images/pic.jpg or absolute: https://example.com/pic.png).
alt (Alternative Text) — Written fallback text describing the image for accessibility (screen readers), image fallback, and SEO.
<img src="./images/Passport Photo.jpg" alt="Passport Photo">

Hyperlinks & Anchors (<a>)

<a> ... </a> Inline Element

Creates hyperlinks to navigate between web pages, files, or specific page sections.

Attributes & Link Types
href (Hypertext Reference) — Destination URL.
External Link: href="https://www.chaicode.com"
Internal / Local Link: href="./01_intro.html"
<a href="https://www.chaicode.com">Go to Chai Aur Code</a>
<a href="./01_intro.html">Go to intro.HTML</a>
