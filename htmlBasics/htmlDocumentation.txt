1. WHAT IS HTML?
--------------------------------------------------------------------------------
HTML stands for HyperText Markup Language. It provides the skeleton and structural
foundation of all web pages. It uses "tags" enclosed in angle brackets (< >) to
tell web browsers how to structure and display text, images, links, and media.

Tags usually come in pairs: an opening tag (e.g., <p>) and a closing tag (e.g., </p>).
Some tags do not require a closing tag; these are called "void" or "self-closing" tags
(e.g., <img>, <meta>).

2. CORE DOCUMENT STRUCTURE (THE HTML5 BOILERPLATE)
================================================================================

Every modern HTML document begins with a standardized foundation:

--------------------------------------------------------------------------------
Element: <!DOCTYPE html>
--------------------------------------------------------------------------------
- Description: Document type declaration. Not an HTML tag, but an instruction to the
  browser.
- Purpose / Use Case: Tells the browser to interpret and render the page using the
  modern HTML5 standard (prevents "quirks mode").
- Example:
  <!DOCTYPE html>

--------------------------------------------------------------------------------
Element: <html> ... </html>
--------------------------------------------------------------------------------
- Description: The root element of an HTML document. Wraps all other content.
- Attributes:
  * lang="en": Specifies the primary language of the document (e.g., "en" for English,
    "es" for Spanish, "hi" for Hindi).
- Purpose / Use Case: Essential for search engines (SEO), browser translation tools,
  and screen readers to pronounce words correctly.
- Example:
  <html lang="en"> ... </html>

--------------------------------------------------------------------------------
Element: <head> ... </head>
--------------------------------------------------------------------------------
- Description: Container for machine-readable metadata about the page.
- Purpose / Use Case: Contains settings, title, scripts, and stylesheets. Content
  inside <head> is NOT directly rendered as visible body text on the page.
- Example:
  <head> ... </head>

--------------------------------------------------------------------------------
Element: <meta> (Inside <head>)
--------------------------------------------------------------------------------
- Description: Self-closing tag providing metadata about the HTML document.
- Key Elements & Attributes:
  * <meta charset="UTF-8">:
    - Purpose: Defines character encoding. "UTF-8" supports virtually all characters,
      alphabets, symbols, and emojis across the globe.
  * <meta name="viewport" content="width=device-width, initial-scale=1.0">:
    - Purpose: Configures the browser viewport for mobile responsiveness.
      "width=device-width" sets the page width to the screen width of the device.
      "initial-scale=1.0" sets the initial zoom level when the page loads.
- Examples:
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

--------------------------------------------------------------------------------
Element: <title> ... </title> (Inside <head>)
--------------------------------------------------------------------------------
- Description: Sets the title of the document.
- Purpose / Use Case: Displayed in the browser tab, bookmarks bar, and search engine
  results pages (SERPs).
- Example:
  <title>First HTML</title>

--------------------------------------------------------------------------------
Element: <body> ... </body>
--------------------------------------------------------------------------------
- Description: Represents the main body of the document.
- Purpose / Use Case: Contains all visible content displayed to the user (headings,
  paragraphs, images, links, forms, etc.).
- Example:
  <body> ... </body>

3. CONTENT ELEMENTS COVERED
================================================================================

--------------------------------------------------------------------------------
A. HEADING TAGS: <h1>, <h2>, <h3> (Up to <h6>)
--------------------------------------------------------------------------------
- Description: Defines semantic headings and subheadings for content organization.
- Levels:
  * <h1>: Top-level / most important heading. By best practice, use only ONE <h1>
    per page for SEO and accessibility.
  * <h2>: Major section headings under <h1>.
  * <h3>: Sub-section headings under <h2>.
  (HTML supports headings from <h1> down to <h6> in decreasing order of importance).
- Purpose / Use Case: Establishes a hierarchical document outline. Helps screen readers
  navigate sections and helps search engine crawlers understand key topics.
- Examples:
  <h1>Lorem ipsum dolor sit amet.</h1>
  <h2>Lorem ipsum dolor sit amet, consectetur adipisicing elit.</h2>
  <h3>Lorem ipsum dolor sit amet consectetur adipisicing elit.</h3>

--------------------------------------------------------------------------------
B. IMAGE TAG: <img>
--------------------------------------------------------------------------------
- Description: Self-closing (void) element used to embed images on the page.
- Key Attributes:
  * src (Source): Path or URL pointing to the image file. Can be relative
    (e.g., "./images/Passport Photo.jpg") or absolute (e.g., "https://example.com/pic.png").
  * alt (Alternative Text): Text description of the image.
    - Accessibility: Read aloud by screen readers for visually impaired users.
    - Fallback: Displayed on the page if the image fails to load (broken link/slow connection).
    - SEO: Helps search engines index and understand the image content.
- Purpose / Use Case: Displaying product images, user profile photos, logos, banners, etc.
- Example:
  <img src="./images/Passport Photo.jpg" alt="Passport Photo">

--------------------------------------------------------------------------------
C. ANCHOR / HYPERLINK TAG: <a> ... </a>
--------------------------------------------------------------------------------
- Description: Inline element that creates hyperlinks to other web pages, files,
  email addresses, or locations on the same page.
- Key Attributes:
  * href (Hypertext Reference): The destination address/URL where the user is
    redirected when clicking the link.
- Purpose / Use Case: Navigation menus, external site links, downloadable files, and
  internal section jumping.
- Example:
  <a href="https://www.chaicode.com">Go to Chai Aur Code</a>

5. TOOLING & WORKFLOW HIGHLIGHTS COVERED
================================================================================

- Live Server ("Go Live"):
  * A local development server that reloads the browser when files change.
  * Requires files to be saved to disk. Turning on "File > Auto Save" enables
    automatic live updates without clicking refresh.

- Emmet Abbreviations:
  * Built-in syntax for generating HTML quickly by typing shorthand and pressing Tab.
  * Examples:
    - !               -> Generates entire HTML5 boilerplate
    - h1{My Title}    -> <h1>My Title</h1>
    - a[href="#"]     -> <a href="#"></a>
    - img[src="" alt=""] -> <img src="" alt="">
    - ul>li*3         -> Creates an unordered list with 3 list items
