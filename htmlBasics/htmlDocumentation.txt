1. WHAT IS HTML?
--------------------------------------------------------------------------------
HTML stands for HyperText Markup Language. It provides the skeleton and structural
foundation of all web pages. It uses "tags" enclosed in angle brackets (< >) to
tell web browsers how to structure and display text, images, links, tables, forms,
media, and semantic layout sections.

Tags usually come in pairs: an opening tag (e.g., <p>) and a closing tag (e.g., </p>).
Some tags do not require a closing tag; these are called "void" or "self-closing" tags
(e.g., <img>, <meta>, <input>).


================================================================================
2. CORE DOCUMENT STRUCTURE (THE HTML5 BOILERPLATE)
================================================================================

--------------------------------------------------------------------------------
Element: <!DOCTYPE html>
--------------------------------------------------------------------------------
- Description: Document type declaration.
- Purpose / Use Case: Instructs the browser to render using modern HTML5 standards.
- Example:
  <!DOCTYPE html>

--------------------------------------------------------------------------------
Element: <html> ... </html>
--------------------------------------------------------------------------------
- Description: Root container element wrapping all page contents.
- Attributes:
  * lang="en": Declares the document language for search engines (SEO) and screen readers.
- Example:
  <html lang="en"> ... </html>

--------------------------------------------------------------------------------
Element: <head> ... </head>
--------------------------------------------------------------------------------
- Description: Metadata container. Content inside is invisible on the page body.
- Key Child Elements:
  * <meta charset="UTF-8">: Unicode character encoding for international text.
  * <meta name="viewport" content="width=device-width, initial-scale=1.0">: Mobile scaling.
  * <title>Page Title</title>: Tab title and search engine headline.
- Example:
  <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>Gym workout</title>
  </head>

--------------------------------------------------------------------------------
Element: <body> ... </body>
--------------------------------------------------------------------------------
- Description: Represents the visible canvas of the web document.
- Example:
  <body> ... </body>

3. SEMANTIC HTML5 LAYOUT & MEANING
================================================================================
Semantic tags convey meaning and purpose to search engines and accessibility tools
(unlike generic <div> containers).

--------------------------------------------------------------------------------
A. <header> ... </header>
--------------------------------------------------------------------------------
- Description: Introductory container for a page or article.
- Purpose: Typically houses site logos, primary headings, author branding, and top menus.

--------------------------------------------------------------------------------
B. <hgroup> ... </hgroup>
--------------------------------------------------------------------------------
- Description: Groups multi-level headings together (e.g., an <h1> title and its <h2>
  subtitle or tagline) to indicate they form a single heading unit.
- Example:
  <hgroup>
      <h1>Learn to create websites</h1>
      <h2>You can learn with hitesh and build your own websites</h2>
  </hgroup>

--------------------------------------------------------------------------------
C. <nav> ... </nav>
--------------------------------------------------------------------------------
- Description: Semantic container dedicated exclusively to primary navigation links.
- Purpose: Screen readers recognize this section and allow users to jump straight
  to page menus.
- Example:
  <nav>
      <ul>
          <li><a href="#">Home</a></li>
          <li><a href="#">About Us</a></li>
          <li><a href="#">Contact Us</a></li>
      </ul>
  </nav>

--------------------------------------------------------------------------------
D. <article> ... </article>
--------------------------------------------------------------------------------
- Description: Self-contained, independently distributable composition (e.g. blog post,
  forum thread, newspaper article, product card). Could stand alone outside the page.

--------------------------------------------------------------------------------
E. <section> ... </section>
--------------------------------------------------------------------------------
- Description: Thematic standalone section of a document, typically with its own heading.

--------------------------------------------------------------------------------
F. <time> ... </time>
--------------------------------------------------------------------------------
- Description: Semantic representation of a date, time, or duration.
- Key Attribute:
  * datetime="YYYY-MM-DD": Machine-readable ISO format for search engines and calendars.
- Example:
  <time datetime="2024-08-02">August 2nd</time>

--------------------------------------------------------------------------------
G. <code> ... </code>
--------------------------------------------------------------------------------
- Description: Inline element representing a short fragment of computer code.
  Rendered in a monospace font by default.
- Example:
  <code>console.log("hitesh")</code>

--------------------------------------------------------------------------------
H. <footer> ... </footer>
--------------------------------------------------------------------------------
- Description: The closing container for a document or section.
- Purpose: Holds copyright notices, author info, site maps, and legal disclaimers.

--------------------------------------------------------------------------------
I. <address> ... </address>
--------------------------------------------------------------------------------
- Description: Contact information for the author or owner of the page/article.
  Renders in italics by default.
- Example:
  <address>Add Your Address Here</address>

--------------------------------------------------------------------------------
J. &copy; (Character Entity)
--------------------------------------------------------------------------------
- Description: HTML entity used to output the copyright symbol © without encoding errors.
- Example:
  <p>&copy; Chaicode 2024</p>

4. MEDIA ELEMENTS: <img>, <figure>, <figcaption>, <video>
================================================================================

--------------------------------------------------------------------------------
A. IMAGE: <img>
--------------------------------------------------------------------------------
- Description: Void/self-closing element embedding an image.
- Attributes:
  * src="...": Path to image file (relative or absolute).
  * alt="...": Description for screen readers and SEO.
  * title="...": Tooltip text displayed when hovering the cursor over the image.
  * width="...": Explicit display width in pixels (e.g., width="200" or width="200px").
- Example:
  <img src="./images/hc.png" title="Hitesh" width="200px" alt="profile photo">

--------------------------------------------------------------------------------
B. FIGURE & CAPTION: <figure> and <figcaption>
--------------------------------------------------------------------------------
- Description:
  * <figure>: Self-contained content container (image, diagram, code listing).
  * <figcaption>: Caption or description for the <figure>. Placed as the first or
    last child element inside <figure>.
- Example:
  <figure>
      <img src="images/hc.png" alt="Dinosaur skeleton" width="200">
      <figcaption>A T-Rex on display in the Manchester University Museum.</figcaption>
  </figure>

--------------------------------------------------------------------------------
C. VIDEO: <video> ... </video>
--------------------------------------------------------------------------------
- Description: Embeds a native HTML5 video player without external plugins.
- Key Attributes:
  * src="...": Path to the video file (.mp4, .webm).
  * width="...": Display width of the video player.
  * controls: Boolean attribute enabling browser's native playback controls
    (play, pause, scrubber, volume, fullscreen).
  * controlslist="...": Fine-tunes control buttons (e.g., "noremoteplayback", "nodownload").
- Example:
  <video src="./images/chai_pe_charcha-1080.mp4" width="400px" controls controlslist="noremoteplayback"></video>


================================================================================
5. CONTENT & STRUCTURAL ELEMENTS
================================================================================

--------------------------------------------------------------------------------
A. HEADING TAGS: <h1> to <h6>
--------------------------------------------------------------------------------
- Description: Block-level semantic headings.
- Levels: <h1> (single main page title) down to <h6> (deep subheadings).

--------------------------------------------------------------------------------
B. STRUCTURAL DIVISION: <div> ... </div>
--------------------------------------------------------------------------------
- Description: Generic block container used for CSS layout styling and script grouping
  when no semantic tag applies.

--------------------------------------------------------------------------------
C. PARAGRAPHS & FORMATTING: <p> and <strong>
--------------------------------------------------------------------------------
- <p>: Block-level paragraph text with vertical spacing.
- <strong>: Inline element signifying strong semantic importance (rendered bold).

--------------------------------------------------------------------------------
D. LISTS: <ul> and <li>
--------------------------------------------------------------------------------
- <ul>: Unordered bulleted list container.
- <li>: Individual list item inside <ul> or <ol>.


================================================================================
6. TABLES: <table>, <tr>, <th>, <td>
================================================================================
- <table>: Outer container wrapper for tabular grid data.
- <tr>: Table row.
- <th>: Table header cell (bold and centered by default).
- <td>: Standard table data cell.


================================================================================
7. FORMS & USER INPUTS: <form>, <label>, <input>, <select>, <button>
================================================================================

- Crucial Concept: "name" vs "id"
  * id: Client-side unique identity. Used by <label for="id">, CSS (#id), and JavaScript.
    Never sent to the server.
  * name: Server-side key sent with the submitted form data (key=value). Inputs without
    a name attribute are NOT submitted to the server!

- Common Input Types:
  * type="text" with placeholder="..."
  * type="password" (masked)
  * type="checkbox"
  * type="color"
  * <select> and <option value="..."> for dropdowns
  * <button type="submit"> and <button type="reset">
