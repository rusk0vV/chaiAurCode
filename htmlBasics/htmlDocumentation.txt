1. WHAT IS HTML?
--------------------------------------------------------------------------------
HTML stands for HyperText Markup Language. It provides the skeleton and structural
foundation of all web pages. It uses "tags" enclosed in angle brackets (< >) to
tell web browsers how to structure and display text, images, links, tables, and forms.

Tags usually come in pairs: an opening tag (e.g., <p>) and a closing tag (e.g., </p>).
Some tags do not require a closing tag; these are called "void" or "self-closing" tags
(e.g., <img>, <meta>, <input>).

2. CORE DOCUMENT STRUCTURE (THE HTML5 BOILERPLATE)
================================================================================

--------------------------------------------------------------------------------
Element: <!DOCTYPE html>
--------------------------------------------------------------------------------
- Description: Document type declaration.
- Purpose / Use Case: Instructs the browser to render using modern HTML5 standards.
- Example:
  <!DOCTYPE html>

--------------------------------------------------------------------------------
Element: <html> ... </html>
--------------------------------------------------------------------------------
- Description: Root container element wrapping all page contents.
- Attributes:
  * lang="en": Declares the document language for search engines (SEO) and screen readers.
- Example:
  <html lang="en"> ... </html>

--------------------------------------------------------------------------------
Element: <head> ... </head>
--------------------------------------------------------------------------------
- Description: Metadata container. Content inside is invisible on the page body.
- Key Child Elements:
  * <meta charset="UTF-8">: Unicode character encoding for international text.
  * <meta name="viewport" content="width=device-width, initial-scale=1.0">: Mobile scaling.
  * <title>Page Title</title>: Tab title and search engine headline.
- Example:
  <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <title>Document</title>
  </head>

--------------------------------------------------------------------------------
Element: <body> ... </body>
--------------------------------------------------------------------------------
- Description: Represents the visible canvas of the web document.
- Example:
  <body> ... </body>

3. CONTENT & STRUCTURAL ELEMENTS
================================================================================

--------------------------------------------------------------------------------
A. HEADING TAGS: <h1> to <h6>
--------------------------------------------------------------------------------
- Description: Block-level semantic headings.
- Hierarchy:
  * <h1>: Main page title (Only ONE per page for SEO).
  * <h2>: Major section headings.
  * <h3>: Sub-section headings under <h2>.
  * <h4> to <h6>: Further granular subsection headings.
- Example:
  <h1>Lorem ipsum dolor sit amet.</h1>
  <h2>Lorem ipsum dolor sit amet consectetur.</h2>
  <h3>Subheading level 3</h3>
  <h4>Subheading level 4</h4>

--------------------------------------------------------------------------------
B. STRUCTURAL DIVISION: <div> ... </div>
--------------------------------------------------------------------------------
- Description: Generic block-level container ("division").
- Purpose / Use Case:
  * Groups multiple elements into logical sections.
  * Essential target for CSS styling (cards, grids, flexbox wrappers).
  * JavaScript target for manipulating grouped content.
- Example:
  <div>
      <h3>Lorem ipsum dolor sit amet.</h3>
      <h4>Lorem ipsum dolor sit amet.</h4>
      <p>Lorem ipsum <strong>Bruh </strong>dolor sit amet.</p>
  </div>

--------------------------------------------------------------------------------
C. PARAGRAPHS: <p> ... </p>
--------------------------------------------------------------------------------
- Description: Block-level paragraph of text with automatic top/bottom spacing.
- Example:
  <p>Lorem ipsum dolor sit amet.</p>

--------------------------------------------------------------------------------
D. SEMANTIC IMPORTANCE: <strong> ... </strong>
--------------------------------------------------------------------------------
- Description: Inline element indicating strong importance or urgency.
- Visual: Rendered bold by default.
- Semantic Difference:
  * <strong>: Indicates important meaning (screen readers emphasize).
  * <b>: Purely visual bold font with no semantic meaning.
- Example:
  <p>Lorem ipsum <strong>Bruh </strong>dolor sit amet.</p>

--------------------------------------------------------------------------------
E. LISTS: <ul> and <li>
--------------------------------------------------------------------------------
- Description:
  * <ul> (Unordered List): Container for bulleted items.
  * <li> (List Item): Individual item placed inside <ul> or <ol>.
- Example:
  <ul>
      <li>Topic 1</li>
      <li>Topic 2</li>
      <li>Topic 3</li>
  </ul>


================================================================================
4. TABLES: <table>, <tr>, <th>, <td>
================================================================================
- Description: Renders two-dimensional tabular data arranged in rows and columns.
- Elements Breakdown:
  * <table>: Outer container wrapper for the entire table.
  * <tr> (Table Row): Horizontal row of cells.
  * <th> (Table Header): Header cell (bold and centered by default).
  * <td> (Table Data): Standard data cell for numbers, text, or values.
- Example:
  <table>
      <tr>
          <th>Name</th>
          <th>Age</th>
          <th>City</th>
      </tr>
      <tr>
          <td>John</td>
          <td>25</td>
          <td>New York</td>
      </tr>
  </table>

5. FORMS & INPUTS: <form>, <label>, <input>, <select>, <option>, <button>
================================================================================
- Description: Collects interactive user inputs and submits them to a server.

--------------------------------------------------------------------------------
A. <form> ... </form>
--------------------------------------------------------------------------------
- Container for all interactive form controls.

--------------------------------------------------------------------------------
B. <label> ... </label>
--------------------------------------------------------------------------------
- Caption for an input field.
- Attribute:
  * for="id": Matches the input's "id" attribute. Clicking the label focuses the input.

--------------------------------------------------------------------------------
C. <input> (Void / Self-closing)
--------------------------------------------------------------------------------
- Multi-purpose input control determined by the "type" attribute:
  * type="text": Single-line text field.
  * type="password": Text field masking entered characters.
  * type="checkbox": Toggle square for selection.
  * type="color": Color picker dialogue.
- Common Attributes:
  * placeholder="...": Temporary light-gray hint text.
  * name="...": Field identifier sent to the server.
  * id="...": Unique identifier on the page (links with label for="...").

--------------------------------------------------------------------------------
D. <select> and <option>
--------------------------------------------------------------------------------
- Creates a dropdown selection menu.
- Attributes:
  * name="..." on <select>.
  * value="..." on <option> (the submitted value).

--------------------------------------------------------------------------------
E. <button> ... </button>
--------------------------------------------------------------------------------
- Clickable button.
- Attributes:
  * type="submit": Submits the form data.
  * type="reset": Clears all inputs back to original defaults.
  * type="button": Generic clickable button for JavaScript.

- Form Example:
  <form>
      <label for="email">
          Email:
          <input type="text" name="email" id="email" placeholder="test">
      </label>
      <label for="password">
          Password:
          <input type="password" name="password" id="password" placeholder="enter your password">
      </label>
      <label for="Games">
          Basketball: <input type="checkbox" name="game" id="Games">
      </label>
      <label>
          <select name="Games">
              <option value="Cricket">Cricket</option>
              <option value="Baseball">Baseball</option>
          </select>
      </label>
      <label>
          <input type="color" name="color">
      </label>
      <button type="submit">Submit</button>
      <button type="reset">Reset</button>
  </form>

6. MEDIA & LINKS
================================================================================

--------------------------------------------------------------------------------
A. IMAGE: <img>
--------------------------------------------------------------------------------
- Self-closing element.
- Attributes:
  * src: Relative or absolute path to image file.
  * alt: Text description for accessibility, fallbacks, and SEO.
- Example:
  <img src="./images/Passport Photo.jpg" alt="Passport Photo">

--------------------------------------------------------------------------------
B. ANCHOR / HYPERLINK: <a> ... </a>
--------------------------------------------------------------------------------
- Inline element creating hyperlinks.
- Attributes:
  * href: Destination URL (external site or local file).
- Example:
  <a href="https://www.chaicode.com">Go to Chai Aur Code</a>
  <a href="./01_intro.html">Go to intro.HTML</a>
