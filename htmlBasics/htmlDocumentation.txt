1. WHAT IS HTML?
--------------------------------------------------------------------------------
HTML stands for HyperText Markup Language. It provides the skeleton and structural
foundation of all web pages. It uses "tags" enclosed in angle brackets (< >) to
tell web browsers how to structure and display text, images, links, and media.

Tags usually come in pairs: an opening tag (e.g., <p>) and a closing tag (e.g., </p>).
Some tags do not require a closing tag; these are called "void" or "self-closing" tags
(e.g., <img>, <meta>).

2. CORE DOCUMENT STRUCTURE (THE HTML5 BOILERPLATE)
================================================================================

Every modern HTML document begins with a standardized foundation:

--------------------------------------------------------------------------------
Element: <!DOCTYPE html>
--------------------------------------------------------------------------------
- Description: Document type declaration. Not an HTML tag, but an instruction to the
  browser.
- Purpose / Use Case: Tells the browser to interpret and render the page using the
  modern HTML5 standard (prevents "quirks mode").
- Example:
  <!DOCTYPE html>

--------------------------------------------------------------------------------
Element: <html> ... </html>
--------------------------------------------------------------------------------
- Description: The root element of an HTML document. Wraps all other content.
- Attributes:
  * lang="en": Specifies the primary language of the document (e.g., "en" for English,
    "es" for Spanish, "hi" for Hindi).
- Purpose / Use Case: Essential for search engines (SEO), browser translation tools,
  and screen readers to pronounce words correctly.
- Example:
  <html lang="en"> ... </html>

--------------------------------------------------------------------------------
Element: <head> ... </head>
--------------------------------------------------------------------------------
- Description: Container for machine-readable metadata about the page.
- Purpose / Use Case: Contains settings, title, scripts, and stylesheets. Content
  inside <head> is NOT directly rendered as visible body text on the page.
- Example:
  <head> ... </head>

--------------------------------------------------------------------------------
Element: <meta> (Inside <head>)
--------------------------------------------------------------------------------
- Description: Self-closing tag providing metadata about the HTML document.
- Key Elements & Attributes:
  * <meta charset="UTF-8">:
    - Purpose: Defines character encoding. "UTF-8" supports virtually all characters,
      alphabets, symbols, and emojis across the globe.
  * <meta name="viewport" content="width=device-width, initial-scale=1.0">:
    - Purpose: Configures the browser viewport for mobile responsiveness.
      "width=device-width" sets the page width to the screen width of the device.
      "initial-scale=1.0" sets the initial zoom level when the page loads.
- Examples:
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

--------------------------------------------------------------------------------
Element: <title> ... </title> (Inside <head>)
--------------------------------------------------------------------------------
- Description: Sets the title of the document.
- Purpose / Use Case: Displayed in the browser tab, bookmarks bar, and search engine
  results pages (SERPs).
- Example:
  <title>First HTML</title>

--------------------------------------------------------------------------------
Element: <body> ... </body>
--------------------------------------------------------------------------------
- Description: Represents the main body of the document.
- Purpose / Use Case: Contains all visible content displayed to the user (headings,
  paragraphs, images, links, forms, etc.).
- Example:
  <body> ... </body>

3. CONTENT & STRUCTURAL ELEMENTS
================================================================================

--------------------------------------------------------------------------------
A. HEADING TAGS: <h1> to <h6>
--------------------------------------------------------------------------------
- Description: Defines semantic headings and subheadings for content organization.
  Headings are block-level elements.
- Levels:
  * <h1>: Top-level / most important heading. Best practice: Only ONE <h1> per page.
  * <h2>: Major section headings.
  * <h3>: Sub-section headings under <h2>.
  * <h4>: Sub-topics inside <h3>.
  * <h5> & <h6>: Deep granular headings.
- Purpose / Use Case: Establishes a hierarchical document outline. Helps screen readers
  navigate sections and search engine crawlers index key topics.
- Example:
  <h1>Lorem ipsum dolor sit amet.</h1>
  <h2>Lorem ipsum dolor sit amet consectetur, adipisicing elit. Fuga, voluptatem?</h2>
  <h3>Lorem ipsum dolor sit amet.</h3>
  <h4>Lorem ipsum dolor sit amet consectetur adipisicing elit. In, veritatis?</h4>

--------------------------------------------------------------------------------
B. STRUCTURAL DIVISION: <div> ... </div>
--------------------------------------------------------------------------------
- Description: Generic block-level container. Stands for "division".
- Purpose / Use Case:
  * Groups multiple elements together (headings, paragraphs, lists).
  * Serves as a target for CSS layout styling (cards, wrappers, flexbox/grid containers).
  * Has no inherent semantic meaning by itself, making it completely flexible.
- Example:
  <div>
      <h3>Lorem ipsum dolor sit amet.</h3>
      <h4>Lorem ipsum dolor sit amet consectetur adipisicing elit.</h4>
      <p>Lorem ipsum <strong>Bruh </strong>dolor sit amet.</p>
  </div>

--------------------------------------------------------------------------------
C. PARAGRAPHS: <p> ... </p>
--------------------------------------------------------------------------------
- Description: Block-level element representing a paragraph of text.
- Purpose / Use Case: Displays regular blocks of body text. Browsers automatically add
  vertical margins (spacing) above and below each <p> element.
- Example:
  <p>Lorem ipsum dolor sit amet.</p>

--------------------------------------------------------------------------------
D. SEMANTIC IMPORTANCE: <strong> ... </strong>
--------------------------------------------------------------------------------
- Description: Inline element indicating strong importance, seriousness, or urgency.
- Visual Appearance: Renders as bold by default in web browsers.
- Semantic Difference:
  * <strong>: Indicates important meaning. Screen readers may emphasize it vocally.
  * <b>: Purely visual bolding without any semantic importance attached.
- Example:
  <p>Lorem ipsum <strong>Bruh </strong>dolor sit amet.</p>

--------------------------------------------------------------------------------
E. LISTS: <ul> and <li>
--------------------------------------------------------------------------------
- Description:
  * <ul> (Unordered List): Container for a bulleted list of items with no numerical sequence.
  * <li> (List Item): Individual item inside a list. Must always be inside a parent <ul> or <ol>.
  * <ol> (Ordered List - Related): Sequential numbered list (1, 2, 3...).
- Purpose / Use Case: Navigation menus, feature lists, bullet points, topic outlines.
- Example:
  <ul>
      <li>Topic 1</li>
      <li>Topic 2</li>
      <li>Topic 3</li>
  </ul>

--------------------------------------------------------------------------------
F. IMAGE TAG: <img>
--------------------------------------------------------------------------------
- Description: Self-closing (void) element used to embed images on the page.
- Key Attributes:
  * src (Source): Path or URL pointing to the image file.
    - Relative: "./images/Passport Photo.jpg"
    - Absolute: "https://example.com/photo.jpg"
  * alt (Alternative Text): Text description of the image.
    - Accessibility: Read aloud by screen readers for visually impaired users.
    - Fallback: Displayed if the image fails to load.
    - SEO: Helps search engines index and rank the image.
- Purpose / Use Case: Displaying product images, user profile photos, logos, banners, etc.
- Example:
  <img src="./images/Passport Photo.jpg" alt="Passport Photo">

--------------------------------------------------------------------------------
G. ANCHOR / HYPERLINK TAG: <a> ... </a>
--------------------------------------------------------------------------------
- Description: Inline element that creates hyperlinks to other web pages or files.
- Key Attributes:
  * href (Hypertext Reference): The destination address/URL.
    - External Link: href="https://www.chaicode.com"
    - Internal / Relative Link: href="./01_intro.html"
- Purpose / Use Case: Navigation menus, external site links, downloadable files, and
  internal page routing.
- Example:
  <a href="https://www.chaicode.com">Go to Chai Aur Code</a>
  <a href="./01_intro.html">Go to intro.HTML</a>

5. TOOLING & EMMET SHORTCUTS
================================================================================

- Emmet Abbreviations (Type and press Tab / Enter):
  * !                       -> Generates full HTML5 boilerplate
  * ul>li*3{Topic $}        -> <ul> with 3 numbered <li> items
  * div>h3+h4+p>strong      -> <div> containing <h3>, <h4>, and <p> with <strong>
  * h1{Title}+h2{Subtitle}  -> Consecutive headings
  * a[href="url"]{text}     -> <a href="url">text</a>
  * img[src="" alt=""]      -> <img src="" alt="">
