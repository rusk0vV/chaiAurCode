01

To-Do List with LocalStorage (01_todo-localstorage)

A dark-mode task manager that lets users add, complete, and delete tasks. It keeps an in-memory tasks array synchronized with both the browser's localStorage (so tasks survive page reloads) and the live DOM list (#todo-list).

System Architecture & Data Workflow
Layer 1 • UI
DOM Tree
#todo-input, #add-task-btn, #todo-list
Layer 2 • Memory
JS State Array
tasks = [{ id, text, completed }]
Layer 3 • Persistence
LocalStorage
JSON.stringify() / JSON.parse()
1. Page Load
DOMContentLoaded → JSON.parse(localStorage) → tasks.forEach(renderTask)
2. Add Task
Click "Add Task" → tasks.push(newTask) → saveTasks() → renderTask(newTask)
3. Toggle Done
Click <li> → task.completed = !task.completed → li.classList.toggle("completed") → saveTasks()
4. Delete Task
Click <button> → e.stopPropagation() → tasks.filter(...) → li.remove() + saveTasks()
