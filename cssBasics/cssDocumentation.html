The 3 Ways to Apply CSS & Specificity

Inline vs Internal vs External Architecture

CSS (Cascading Style Sheets) can be attached to HTML documents in three distinct ways:

Methods Comparison
1. Inline CSS — Written directly inside an HTML tag using the style attribute.
Use Case: Quick overrides and test styling. Highest specificity priority.
2. Internal CSS (Embedded) — Written inside a <style> block in the <head>.
Use Case: Single-page sites or isolated page styling.
3. External CSS (Recommended) — Written in a dedicated .css file linked via <link rel="stylesheet" href="style.css"> in <head>.
Use Case: Industry standard. Reusable across multiple pages, cleanest separation of concerns, and cached by browsers for lightning-fast loads.
<!-- 1. Inline CSS -->
<h1 style="color: orangered;">Orangered Heading</h1>

<!-- 2. Internal CSS (in <head>) -->
<style>
  .browntext { color: brown; }
</style>

<!-- 3. External CSS (in <head>) -->
<link rel="stylesheet" href="style.css">
⚡
Specificity Rule: Inline CSS overrides Internal and External CSS rules. If conflicting styles target the same element, the most specific rule wins.

CSS Selectors

Element, Class & Pseudo-Class Targeting Rules
Selector Types
Element (Type) Selector — Targets all HTML elements of that tag name (e.g., p, h2, body, button).
Class Selector (.) — Targets elements with a specific class="..." attribute. Reusable across multiple elements on the same page.
Pseudo-Class (:) — Targets elements based on their dynamic user-interaction state (e.g., button:hover).
/* 1. Element Selector */
p {
  color: cornflowerblue;
}

/* 2. Class Selector (prefixed with dot) */
.card {
  background-color: #d5d4d4;
}

/* 3. Pseudo-class on Hover */
button:hover {
  background-color: #0741ac;
}

The CSS Box Model

Margin • Border • Padding • Content Layout Fundamentals

Every HTML element is rendered by the browser as a rectangular box consisting of four concentric layers:

Margin (Outer Spacing between elements)
Border (The boundary line)
Padding (Space inside border around text)
Content (Text / Image)
Box Model Properties
padding: 30px; — Adds 30px of breathing room inside the card between border and text.
border: 1px solid black; — Draws a solid black border line of 1px width.
border-radius: 8px; — Rounds the corners of the border by 8 pixels.
margin-bottom: 15px; — Pushes the next adjacent element down by 15px.
width: 300px; — Fixes the horizontal dimension of the element's content area.
.card {
  width: 300px;
  padding: 30px;
  border-radius: 8px;
  background-color: #d5d4d4;
}

Modern Flexbox Layout

display: flex & Viewport Centering Alignment

Flexbox is a 1-dimensional CSS layout model designed to distribute space and align items seamlessly.

The Ultimate Centering Technique
height: 100vh; — Expands body to occupy 100% of the viewport's visible height.
display: flex; — Turns the parent into a flex container.
justify-content: center; — Centers children horizontally along the main axis.
align-items: center; — Centers children vertically along the cross axis.
flex-direction: column; — Stacks items vertically (used on forms to stack input fields one above another).
/* Perfect Screen-Center Login Page */
body {
  margin: 0;
  height: 100vh;
  display: flex;
  justify-content: center; /* Horizontal Center */
  align-items: center; /* Vertical Center */
}

form {
  display: flex;
  flex-direction: column; /* Stack inputs downwards */
}

Colors & Typography

color • background-color • font-family Styling
Core Styling Properties
color — Sets the font color (e.g. brown, orangered, #fff).
background-color — Sets background fill (e.g. #1a1a1a dark body, #1b81da blue button).
font-family: Arial, Helvetica, sans-serif; — Font fallback stack: browser uses Arial, falls back to Helvetica, then any generic sans-serif font.
font-size: 25px; — Specifies text height.
text-align: center; — Centers text horizontally within its container.
h2 {
  color: #1a50a0;
  text-align: center;
  margin-bottom: 20px;
}

Interactive States (:hover)

:hover Pseudo-Class Interactivity

Applies styles dynamically when the user points to an element with a cursor.

button {
  background-color: #1b81da; /* Light blue normal state */
  color: #fff;
  padding: 10px;
  border-radius: 8px;
}

button:hover {
  background-color: #0741ac; /* Darker blue hover state */
}

CSS Units (px vs vh)

Units: px & vh Measurements
px (Pixels) — Absolute unit. 1px = 1 dot on screen. Ideal for borders, fixed padding, and controlled card widths (e.g. width: 300px;).
vh (Viewport Height) — Relative unit. 1vh = 1% of the browser window's height. 100vh = exactly 100% full screen height. Essential for full-height layouts.
